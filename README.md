## Зачем это

Веб-интерфейс FESB хорош, когда работаешь с одним доменом. Когда доменов
двести пятьдесят, простые вопросы становятся дорогими: **на какой брокер
смотрит трассировка во всех СОПС сразу, через какие адреса шина
разговаривает с внешним миром, что застряло прямо сейчас и когда истекает
сертификат.**

FESB Toolkit отвечает на них за один экран. Он не заменяет веб-интерфейс —
он закрывает то, что там приходится делать руками по одному домену.

Работает с папкой выгрузки конфигурации и с живым сервером по REST API.
Кроссплатформенный: Windows, macOS, Linux.

## Что внутри

- 🎯 **Массовая правка трассировки** — брокер, очередь и режим сразу в сотнях
  доменов. Пробный прогон показывает результат до записи, резервные копии
  создаются рядом с файлами, сверка с сервером проверяет, что доехало.
- 🔌 **Отчёт по точкам входа и выхода** — все адреса, через которые шина
  говорит наружу: протокол, порт, TLS, шифры, авторизация, потоки Jetty.
  Двадцать три столбца, группировка по узлам, выгрузка в Excel. История
  собранных отчётов остаётся на диске.
- 🗺 **Живой обзор стенда** — домены и их СОПС со счётчиками, схемы маршрутов
  слева направо, связи «кто кого вызывает», незавершённые обмены с указанием
  шага, на котором они висят.
- 📨 **Очереди** — менеджеры, очереди и сообщения в них, с поиском по телу
  сообщения, а не только по идентификатору.
- 🔐 **Безопасность стенда** — сертификаты хранилищ со сроками действия,
  роли и права человеческими словами, кто сейчас в системе и как устроен вход.
- 📋 **Журналы и аудит** — разобранные на уровень, источник и текст; кто
  и что менял на сервере.
- ⚙️ **Обслуживание** — модули, константы всех трёх уровней, точки
  восстановления, запуск и остановка доменов.

Интерфейс двуязычный (English / русский), со светлой и тёмной темой.

## Как это работает

**Ничего лишнего наружу.** Приложение ходит только на тот сервер, адрес
которого вы ввели. Своих серверов, телеметрии и сбора статистики нет.
Подключения хранятся на вашей машине; пароль сохраняется только если вы
сами это разрешили.

**Трассировка правится выгрузкой и загрузкой.** У объектов трассировки нет
отдельных методов в API шины, поэтому режим устроен так: забрать выбранные
домены, поправить файлы, отправить обратно. Тот же путь, что и в файловом
режиме, — просто без ручного скачивания архива.

## Как начать

Скачайте сборку из [релизов](https://github.com/DEADover/FESB-Toolkit/releases)
и запустите. Дальше — либо перетащите в окно папку выгрузки конфигурации,
либо заведите подключение к серверу: достаточно хоста, схему и `/manager`
приложение подберёт само.

Из исходников — нужны [Node 20+](https://nodejs.org) и
[Rust](https://rustup.rs):

```bash
git clone https://github.com/DEADover/FESB-Toolkit
cd FESB-Toolkit
npm install
npm run dev      # разработка
npm run build    # сборка под текущую систему
```

## Стек

Tauri 2 · Rust · React 19 · TypeScript · Vite · Tailwind

Rust держит всю работу с файлами и сетью, интерфейс получает готовые
структуры и прямого доступа к диску не имеет. Разбор XML, сборка архивов
и запись `.xlsx` — свои, без тяжёлых зависимостей.
