## Назначение

Набор инструментов для повседневной работы с интеграционной шиной FESB. Одни закрывают то, чего
в веб-интерфейсе FESB нет, другие делают привычные операции быстрее. Пригодится не всё и не всем: это не замена веб-интерфейсу
и не попытка его повторить.

Набор растёт по рабочим задачам. Операция, которую регулярно приходится
собирать из десятка действий в интерфейсе FESB, становится здесь отдельным
инструментом.

Два режима работы: папка выгрузки конфигурации (или её ZIP) и живой сервер
по REST API.

## Возможности

Ниже — основное из последнего выпуска. Список не полный и от версии к версии
пополняется: набор растёт по задачам, которые встречаются в работе.

- **Сводка по стенду** — сразу после подключения: остановленные домены,
  СОПС с ошибками, зависшие обмены, очереди без читателей, истекающие
  сертификаты, неработающие модули. Каждая строка ведёт на свой экран.
  По желанию — наблюдение в фоне с системными уведомлениями о новом.
- **Поиск по стенду** — ⌘K / Ctrl+K находит не только разделы, но и домены,
  СОПС, константы (в том числе по значению) и очереди.
- **Массовая правка трассировки** — брокер, очередь, режим и остальные
  параметры объекта трассировки сразу во многих доменах: события, клиент,
  очередь событий, что записывать в событие, префиксы. Рядом с каждым
  параметром видно, какие значения у выбранных объектов сейчас; недостающее
  свойство дописывается, поля с Groovy-выражениями не затрагиваются.
- **Отчёт по точкам входа и выхода** — адреса, которыми FESB говорит наружу:
  схема, порт, TLS, шифры, авторизация, состояние, потоки Jetty. Локальные
  очереди — с менеджером, который их держит. Выгрузка в Excel.
- **Трассировка по всему серверу** — какие СОПС трассируются и через какие
  объекты, включая остановленные домены. Отобранные СОПС запускаются,
  останавливаются и обнуляют счётчики разом.
- **Инвентаризация стенда** — домены и СОПС со счётчиками, схемы маршрутов,
  связи «кто кого вызывает» по адресам концов, незавершённые обмены
  с переходом в журнал обмена.
- **Очереди** — менеджеры QMS, QME и RQMS, их очереди и сообщения. Поиск
  идёт по всей очереди, а не по первой странице: очередь выгружается целиком
  одним запросом и просматривается вместе с телами.
- **Поиск обмена по ключу** — номер заказа, ИНН или ID документа ищется
  разом в журналах, среди незавершённых обменов и в сообщениях всех очередей.
  Сверху — где обмен сейчас и чем закончился, ниже — через какие СОПС он
  прошёл и на чём основан ответ.
- **Разбор очередей ошибок** — очереди ошибок видны сразу, у каждого
  сообщения — откуда оно пришло. Отмеченные сообщения возвращаются в исходную
  очередь, перекладываются, копируются или удаляются — одним действием,
  после предпросмотра.
- **Безопасность стенда** — сертификаты хранилищ с остатком срока действия,
  роли и права, активные сессии, настройки входа.
- **Журналы и аудит** — с разбором по уровню, источник и текст.
- **Клиент AMQP** — отправка с заготовками, переменными, пачками и CSV, приём
  с отбором и записью, просмотр и чистка очередей, переливка сообщений между
  брокерами, клиенты брокера, история и статистика.
- **Сравнение стендов** — домены, СОПС и константы двух стендов или одного
  стенда во времени по снимкам. Найденную разницу можно перенести:
  константы — после предпросмотра, домены — копированием.
- **Обслуживание** — модули, точки восстановления, запуск и остановка доменов.
  Константы трёх уровней правятся на месте, по всему стенду ищутся по значению
  и заменяются массово с предпросмотром.

- **Стенды в файле** — список подключений выгружается в файл и загружается
  из него: передать набор стендов коллеге или перенести на другую машину.
  Пароли в файл не попадают.

Интерфейс двуязычный (русский, английский), светлая и тёмная темы.

## Установка

Готовые сборки — в [релизах](https://github.com/DEADover/FESB-Toolkit/releases):
Windows x64 (NSIS, MSI, портативный exe) и macOS на Apple Silicon (dmg).

Первый запуск на macOS через Terminal: ```xattr -r -d com.apple.quarantine /Applications/FESB\ Toolkit.app```

Дальше приложение обновляется само: вскоре после запуска оно проверяет
релизы и предлагает поставить новую версию. Проверить вручную — щелчком
по номеру версии внизу боковой панели. Ставятся только сборки, подписанные
ключом проекта. Установленная через NSIS версия обновляется установщиком
NSIS, через MSI — пакетом MSI. Портативный exe сам себя не заменяет:
приложение предлагает скачать новый файл, подключения и настройки при этом
сохраняются.

## Сборка из исходников

Нужны [Node 20+](https://nodejs.org) и [Rust 1.82+](https://rustup.rs):

```bash
git clone https://github.com/DEADover/FESB-Toolkit
cd FESB-Toolkit
npm install
npm run dev            # разработка
npm run build          # сборка под текущую систему
npm test && npm run test:rust
```

Файлы автообновления релиз получает, только если в секретах репозитория есть
ключ подписи — `TAURI_SIGNING_PRIVATE_KEY` и `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`.
Без него сборка идёт как обычно, но установленные копии о новой версии не узнают.

## Стек

Tauri 2 · Rust · React 19 · TypeScript · Vite · Tailwind

Работа с файлами и сетью целиком в Rust, интерфейс получает готовые структуры
и прямого доступа к диску не имеет. Разбор XML, сборка архивов и запись `.xlsx`
свои, без внешних библиотек.
